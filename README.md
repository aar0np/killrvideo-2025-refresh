# KillrVideo 2025 Refresh

Repo for any documents pertaining to the design and rebuild of KillrVideo v2.

## Docker Compose

The `docker-compose.yml` file in this directory can be used to bring up KillrVideo v2.  It will start up the following services:
 - backend from killrvideo-2025-java
 - frontend from killrvideo-react-frontend

```
docker-compose up
```
or
```
podman-compose up
```
